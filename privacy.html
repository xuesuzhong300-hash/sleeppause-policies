一、功能与适用范围

SleepPause 是 Android 听书辅助应用。当前测试版可在用户授予通知使用权后，通过用户点击按钮尝试暂停喜马拉雅播放。“开始监听”按钮目前仅切换界面状态，不代表已读取健康数据。实时心率辅助暂停、睡眠记录分析和夜间心率趋势为计划开发的功能，尚未启用。

本政策区分现有功能与后续计划。健康功能完成后，开发者将核对并更新数据说明，在首次读取前向用户说明并获取相应授权。未获批或未授权的健康数据不会被读取。

二、处理的数据与用途

功能数据及处理目的当前状态
媒体暂停通过 Android 媒体会话接口获取活动媒体应用的包名、播放状态及会话控制对象，用于查找正在播放的喜马拉雅并发送暂停指令。当前代码不读取或保存通知正文。已实现；需用户授予通知使用权并主动点击。
心率辅助暂停拟读取获授权的实时心率及与分析必要相关的时间信息，在本机短时分析变化，估计可能入睡并尝试暂停音频。计划开发；回调字段、可用性及后台限制待验证。
睡眠回顾拟读取已同步的睡眠记录，包括接口实际提供的入睡、起床时间、时长与睡眠阶段，用于单晚回顾及近期趋势展示。计划开发；具体字段与查询时间范围取决于获批能力及实际返回数据。
夜间心率趋势拟读取获授权的历史心率记录及时间信息，结合睡眠区间显示夜间心率曲线。计划开发；不申请写入数据权限。

心率和睡眠属于敏感个人信息。相关功能将以明确目的、必要范围和用户单独同意为前提；用户拒绝或撤回健康授权，不影响已授权的手动媒体暂停功能。

三、拟采用的保存与传输方式

实时心率计划仅在手机内存中短时处理，停止功能或结束会话后清除。睡眠和历史心率计划在用户查看时按需读取并展示，不另行长期保存，不写入应用数据库、文件、日志或可备份数据。退出相关页面后清除应用持有的展示数据；这些清理机制尚待实现与验证。

SleepPause 不计划建立健康数据服务器，不向自己的服务器上传健康数据，不计划用于广告、出售或对外提供健康数据。华为帐号、运动健康、HMS Core 及其相关服务的认证、授权、同步和数据处理另受其适用说明约束。上述计划不表示华为的数据全部在本机处理或完全不经网络。

四、系统权限与授权

通知使用权由用户在 Android 系统设置中授予，用于取得媒体会话控制能力。此项系统权限能够赋予应用较广的通知访问能力；SleepPause 当前实现只调用媒体会话接口，不保存其他应用的消息通知内容。撤回通知使用权后，媒体会话暂停功能将无法使用。

健康功能启用前，将通过华为支持的授权流程申请实时心脏数据、睡眠数据和心率数据的读取授权。用户可选择拒绝或在华为提供的授权管理页面撤回。界面路径可能随版本变化，届时以实际授权界面为准。

组件用途／接入状态提供方与数据处理说明

核对入口：HMS Core 隐私声明、Health Service Kit 扩展能力 SDK 隐私安全说明。帐号服务和健康功能正式启用前，将按实际集成版本更新适用的具体披露。

六、网页访问与托管

这两份政策网页由 GitHub Pages 托管。网页不提供健康数据上传、登录或表单，不使用本站脚本收集健康数据。网页托管服务在传输和保障访问安全时可能处理 IP 地址、请求时间、浏览器与网络请求等必要访问数据，该处理与手机应用的健康数据处理不同。托管服务适用其公开隐私说明：GitHub 隐私声明。

七、用户选择、清除与联系

用户可以在系统通知使用权设置中关闭 SleepPause 授权。健康功能上线后，可停止功能、撤回华为健康授权并退出页面以清除应用的临时展示数据。由于本应用计划不长期留存健康记录，应用清除操作不会删除手表、华为运动健康或华为云中保存的源记录；源记录须通过对应服务管理。

用户如需了解数据处理、提出更正、删除或撤回同意请求，可联系上文邮箱。开发者将在核实请求并确认所涉及的数据后处理，不以本应用无法控制的第三方数据为已删除作出承诺。

八、未成年人、政策变更与功能限制

第一阶段测试面向成年用户，不计划向未成年人提供健康数据读取功能。公开发行范围变化时，应先更新适用说明和相关保护措施。

功能、SDK 或数据处理方式变化时，开发者会更新本政策；如涉及新的敏感信息用途或授权，将在启用前告知并按需要重新取得同意。心率变化无法单独确定用户是否入睡，本应用不提供医学诊断、治疗或准确睡眠识别保证。
